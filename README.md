# Mystic BBS 本机双站实验

在一台 Windows 电脑上搭建一主一副两个复古 BBS。用终端发帖、回帖、传文件，再将一封测试邮件从一站投递到另一站。网络只面向这台电脑，不需要公网域名。

本仓库只提供自写的手册、配置说明和诊断工具。Mystic BBS 及 NetRunner 请从[作者的下载页](https://mysticbbs.com/downloads.html)获取。本仓库不附带这些程序、安装包、终端字体或原版菜单。

## 从哪里开始？

- 只想上站：看 [Windows 使用手册](docs/使用手册.md)的「第一次连接」。
- 要复原两站结构：看 [配置表](docs/配置表.md)，按自己的目录填写。
- 启动后连不上：先跑 `scripts/Test-BbsLocal.ps1` 检查本机端口；它不会启动服务或修改配置。
- 做过改动：按 [验收清单](docs/验收清单.md)复测，把「未测」与「不通过」分开记。

默认例子中的主站叫 PRIVATE，副站叫 ORBIT。它们是演示名称；仓库不包含实际站点配置、用户数据库、帖子、私信、密码、日志或备份。Telnet 不加密，因此本项目只在回环地址使用，不配置路由器转发，也不建议将这些端口开放给局域网或公网。
