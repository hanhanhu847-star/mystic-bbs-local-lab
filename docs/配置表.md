# 两站配置表

这些是可手工填写的示例，不是可直接覆盖原站的数据文件。建议使用短目录，例如 `C:\BBS\A` 和 `C:\BBS\B`；两站不得共用数据目录或队列。

| 项目 | 主站 PRIVATE | 副站 ORBIT |
| --- | --- | --- |
| Telnet 地址 | 127.0.0.1:2323 | 127.0.0.1:2324 |
| BinkP 地址 | 127.0.0.1:24554 | 127.0.0.1:24555 |
| 终端连接用途 | 登录、读帖、文件区 | 登录、读取对站送来的测试帖 |
| BinkP 用途 | 站与站之间交换消息数据 | 站与站之间交换消息数据 |

在各站的 `mystic.exe -cfg` 中找各服务的配置：`Adapter Type` 选 IPv4，`IPV4 Adapter` 填 `127.0.0.1`，端口按表填写；不启用不使用的服务。**终端里填的是 127.0.0.1，不代表服务端也只绑定了 127.0.0.1。** 看服务配置和运行后的监听地址。勿用 `0.0.0.0`、`::` 或其他网卡地址来做本机实验。配置选项详见 [Mystic 服务文档](https://wiki.mysticbbs.com/doku.php?id=config_server_servers)。

如需两站互通，分别配置不同的本地 FTN 地址、双方对应的节点、彼此的回环端口以及一致的测试区标签。节点口令由你在本地生成并通过官方配置界面分别填写，不要写进模板或截图。首次验收用手动处理和一次测试消息，不开自动轮询。具体设置见 [EchoMail Nodes](https://wiki.mysticbbs.com/doku.php?id=config_echomail_nodes)。
