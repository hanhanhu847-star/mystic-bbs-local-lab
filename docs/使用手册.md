# 私人 BBS 使用手册

这套 BBS 装在自己的 Windows 电脑上。PRIVATE 是主站，ORBIT 是用来验证站际互通的副站。平时上站只需要启动主站、打开终端、选中保存好的连接。BinkP 是服务器之间的传输，不是给读帖用的第二个登录端口。

## 1. 第一次连接

1. 在 Windows 打开「命令提示符」。输入 `cd /d "<你的主站目录>"`，回车。
2. 运行 `mis.exe server`。保留这个窗口，看到服务器已启动后再打开 NetRunner。
3. 打开 NetRunner，按 `Alt+I`（Immediate Dial，直接连接），输入 `127.0.0.1:2323`。如果出现协议选择，选 Telnet。若你已保存站点，可按 `Alt+D` 打开拨号目录，选中站点后回车。连接 ORBIT 时用示例端口 `2324`，前提是副站已启动。
4. 有「System Password」时，那是站点口令，不是个人登录密码；按你的站点设置正常验证。出现账号提示时再输自己的别名和个人密码。不要把密码贴在工单、截图或 GitHub 上。
5. 退出时先在 BBS 选 Logoff 或 Quit 并确认；确定没有人在使用时，再到对应的 MIS 窗口正常停止服务。不要直接拔掉窗口来代替退出。

## 2. 读帖、搜索、发帖、回帖

1. 在主菜单找 **Messages**，进入你可访问的消息区。**Read Messages** 是读帖，**Find Messages** 是搜索；本次在原版菜单走的是：主菜单 `M` 进消息区，`P` 发帖，`F` 再按 `C` 搜当前区，回车读帖，`R` 回帖，`]` 跟进线程。改过菜单的站点以屏幕提示为准。
2. 自测时只用测试区。以不重复的短标题发一帖，再按标题的关键词搜索。打开结果，核对标题和正文。
3. 在原帖阅读界面选 **Reply**，写一句可辨认的回复并保存。沿线程链接返回原帖，再确认回帖挂在正确主题下。退出后重新登录，检查它是否仍在。
4. 正式内容和测试内容分开，不在正式区反复留测试帖。

## 3. 文件区怎么用

在 **Files** 里进入指定文件区，看清可下载、可上传或受限的提示。原版快捷键是主菜单 `F`，再按 `U` 上传、`L` 列表或 `D` 下载；协议菜单中 `C` 是 XMODEM/CRC。用空白测试区传一个自己写的小文本，先确认传输协议（两端必须选同一种；本次实测通过的是 XMODEM/CRC），再跑上传、文件列表、下载。下载到另一个目录，勿覆盖原件。分别用 `Get-FileHash -Algorithm SHA256 "<文件路径>"` 检查原件和下载件，两串结果一致才算文件来回无损。

## 4. 两站互传消息怎么理解

本次实测的是定向 Netmail：写一封寄往对站的测试邮件 → 发件站导出 → BinkP 传输 → 收件站导入 → 在收件站核对邮件标题和正文。论坛公开区的 EchoMail 另需两站配置对应测试区及导出规则，不把它混成同一个通过项。地址、端口、测试区标签和节点配置应按两站各自的角色填写。连接成功但收件站没有帖子时，分别核对导出、传输、导入；不要把“连接成功”当成“邮件已到”。用一条测试消息做正向，再单独验证反向。建议测试期间关闭自动轮询，确认没有外部节点参与。

在空白测试站配置时：`Networking → Echomail Addresses` 添加站点地址，两站的域都要填写同一个自设测试值，站号则不同。再到 `Echomail Nodes` 配置对方为启用的 BinkP 节点。给接收站填好 SysOp 名后，在发件站节点列表按 `/`，选 `3 Netmail SysOp` 写一封测试邮件。先使用单独的 `ExportEchoMail` 配置导出，再用 `mis poll <目标地址>` 只拨该测试节点；最后在接收端用单独的 `ImportEchoMail` 配置导入。用消息内容验收，别只看发送日志。

## 5. 连不上时

| 看到的现象 | 先检查什么 |
| --- | --- |
| NetRunner 没有欢迎页 | 对应站的 MIS 是否在运行；Telnet 模式和端口是否正确；不要把 BinkP 端口填进 NetRunner |
| 显示「Mystic servers are already running」 | 先确认没有 MIS 进程、没有相应监听。确认是残留的运行锁后，给本站 `semaphore\mis.bsy` 改名留档，再重新启动；不可在服务仍运行时处理 |
| 看到了「System Password」 | 服务已响应，正在等待站点口令；不要关闭这个保护来做测试 |
| 登录后显示找不到菜单 | 查主题和菜单目录，核对安装是否完成；新建测试站优先用较短的目录，不复制正式用户和消息库 |
| 两站能连上但没有收到测试帖 | 先定位卡在导出、传输还是导入，不要先改正式节点口令 |
