# 验收清单

区分原站和空白测试站。不要把空白测试站的通过项当作原站已通过。涉及写入的项目只用测试账号、测试区和自己制作的样本文件。

| 检查项 | 通过标准 |
| --- | --- |
| 启动 | 进程持续运行，启用的端口只有计划中的回环地址 |
| 登录 | 用自己的账号进入主菜单，再正常退出；不需要更改账号权限 |
| 浏览和搜索 | 在本地测试区读到已知主题，按关键词找到它，随机字符串没有结果 |
| 发帖和回帖 | 保存标题和正文，回复挂到原帖，退出后重新登录仍能找到 |
| 文件区 | 用无隐私的小文件跑完上传、列出、下载；比对 SHA-256，确认内容未变 |
| 站务 | 用你自己的管理员账号看得到站务入口；普通测试账号看不到 |
| 两站互传 | 测试帖从发件站生成待发送数据，另一站接收并导入，可在消息区读取正确正文；反向再跑一次 |
| 保持隔离 | 无局域网/公网地址监听，不启用对外路由；正式帖子、私信和账号未参与写入试验 |

仅有 BinkP 握手成功，或者仅看到导出的数据文件，都不是互传验收通过；以对站能读到测试帖为准。

## 本次已记录的测试证据

- 同版本空白测试站：真实本机 Telnet 注册与登录、发帖、回帖和关键词搜索通过；再次登录仍能找到帖子及回帖。
- 文件：用标准 XMODEM/CRC 经本机 Telnet 上传 128 B 自制样本，文件列表可见，重登后下载，逐字节和 SHA-256 一致。
- 站际消息：测试站 A 的一封定向 Netmail 已完成导出、仅本机 BinkP 投递、测试站 B 导入，核对了标题及正文。这个结论不等于测试了公开 EchoMail 区或反向收发。
- 正式站：两站的旧运行锁均已保留备份。处理后，两站实际只监听 127.0.0.1；主站到欢迎界面，副站到原有站点密码提示。正式主站已核实登录及站内消息索引加载；一般版面的读帖、搜索仍未在正式站复测，已在隔离站通过。
